## 👨‍💻 About

I am a **Computer Engineering student and aspiring Software Developer** focused on building practical, scalable, and user-oriented software solutions.

My foundation spans **Python, C, Java, SQL, Flask, data analytics, databases, and software testing fundamentals**, with hands-on experience developing academic software and completing intensive practical training in data analytics.
